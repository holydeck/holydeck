# Provisional icons

`icon-192.png` and `icon-512.png` are placeholders: a flat fill with a plain mark, generated so the
app is installable from its first commit. They carry no wordmark and no final artwork, and they must
be replaced with the real icon set — including a maskable safe area — before a public release.

The 512 icon is declared `any maskable` in the manifest, so its replacement must keep the mark inside
the central 80% of the canvas.
